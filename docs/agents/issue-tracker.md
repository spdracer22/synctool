# Issue tracker: GitHub

Issues and specs live in GitHub Issues for spdracer22/synctool.
Use the gh CLI to create, read, list, comment on, label, and close issues.
Read the full issue body and comments when fetching a ticket.

When a skill says to publish to the issue tracker, create a GitHub issue.

Record blockers in each ticket's "Blocked by" section and use GitHub's
native issue dependencies where available. If unavailable, retain the
issue references in the body. Work tickets whose blockers are closed.

PRs as a request surface: no.
